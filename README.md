# 六面顶压机控制系统

## 项目简介

这是一个基于STM32的六面顶压机控制系统，用于碳素石墨化加工过程中的压力、温度和位置控制。系统采用OLED显示界面，提供直观的用户交互体验。

## 系统特点

- **多轴控制**: 采用三轴步进电机实现精确定位
- **压力监测**: 实时监测和控制工作压力
- **温度控制**: 支持加热、保温和冷却过程控制
- **人机交互**: OLED显示界面，五按键操作系统
- **安全保护**: 具备多重安全保护机制

## 硬件配置

- 主控: STM32F103系列
- 显示: 128x64 OLED屏幕
- 输入: 5按键(上、下、左、右、确认)
- 执行器: 3个步进电机
- 传感器: 压力传感器、温度传感器

## 操作说明

### 按键定义
- ⬆ (上键): 向上选择/增加数值
- ⬇ (下键): 向下选择/减小数值
- ← (左键): 返回/左移
- → (右键): 确认/右移
- OK (确认键): 执行/确认

### 基本操作流程
1. 开机自检
2. 系统校准
3. 参数设置
4. 启动工艺
5. 监控运行
6. 完成出料

## 系统参数

### 压力参数
- 最大压力: 1500 kPa

- 压力精度: 0.1 kPa

### 温度参数
- 最高温度: 200°C
- 最低温度: 0°C
- 温度精度: 1°C

### 时间参数

- 刷新率: 100ms
